# 2026-07-28 Devlog

## 今日摘要

今天完成 AI 預問診系統的大型架構與產品流程升級：後端導入
AMIE-inspired 狀態感知問診、確定性安全分流、SQLite 病例儲存與分層模組；
前端重整病患問診流程及醫師病例工作台；同時補上 TW Core 術語參考、
自動化品質檢查與研究規劃文件。

## 後端與臨床流程

- 將原本集中於 `main.py` 的 FastAPI 程式拆分為 `app`、`domain`、
  `infrastructure`、`knowledge`、`scripts` 等分層模組，保留精簡 ASGI 入口。
- 新增 AMIE-inspired LangGraph 問診引擎，支援結構化主訴抽取、原文 evidence
  驗證、動態選題、條件式 RAG、Mx 背景推理及可稽核的逐輪決策摘要。
- 建立兩層確定性 safety 流程；明確警訊可直接終止問診，語意抽取結果需經
  程式規則判定 urgent／routine，模型不直接決定分級。
- 新增 SQLite consultation repository，支援病例建立、搜尋、分頁、刪除、
  非同步摘要狀態與結構化報告快取。
- routine 與 urgent 流程皆先保存病例並核發編號，再於背景產生 RAG／LLM 摘要，
  避免摘要失敗導致病人無法取得問診編號。
- 新增疼痛區域、問卷 UI、輸入驗證與 TW Core 術語參考領域邏輯。
- 搬移 RAG、LLM 與語料處理工具至新的分層目錄，並更新所有測試匯入路徑。
- 加入合成王大明心臟支架 FHIR 案例與 TW Core 1.0.0 必要定義／ValueSet。

- 擴充身體疼痛區域資料及前後視圖互動，支援更細緻的頭部與身體位置。
- 建立醫師端病例瀏覽器，可搜尋、分頁、選取及二次確認刪除病例。
- 擴充病人資料卡、臨床證據與術語標示，呈現病例時間軸、結構化病歷、
  FHIR coding 與摘要處理狀態。
- 更新後端、FHIR、臨床病歷及術語服務封裝與相關單元測試。
