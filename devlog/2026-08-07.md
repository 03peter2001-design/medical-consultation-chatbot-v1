# 2026-08-07 Devlog

## 今日摘要

今天改善病患結構化問診的可修正性，讓使用者能取消已選選項、以「其他」文字取代
舊選項，並回到上一題重新作答；傳統前端與拆分後的 patient app 維持一致行為。
醫師端則補上無目前就診情境的後臺模式、邀請能力提示，以及 UCC session 失效判斷，
避免登入頁 HTML 或失效回應被誤當成有效 bootstrap。同步更新 OpenAPI 契約、產生型別、
開發待辦與本機部署暫存檔忽略規則。

晚間整合其他工作分支後，另外完成僅限 loopback 的本機驗證 bypass、兩行式 EMR 摘要、
52 類 provisional 問卷草稿、本機 Breeze-ASR-26、CosyVoice3 + MuseTalk Avatar，以及
可切換的 D-ID 瀏覽器 provider。整合部署同步加入 CUDA、模型快取、VRAM 釋放、私有
Avatar service、provider-specific CSP 與部署前驗證。

## 病患問卷操作

- 病患 chat request 新增 `answer`／`back` action；後端在每次有效作答前保存有限長度的
  session 快照，可還原上一題、問卷資料與 AMIE transcript 長度，同時保留整合授權內容。
- chat response 新增 `can_go_back`，兩套病患前端依後端狀態顯示「回到上一題」，返回後
  移除畫面上最後一輪作答與對應 trace，讓病患可重新輸入。
- 單選與複選選項皆可再次點擊取消；輸入「其他」時會清除舊選項，重新點選選項也會
  清除「其他」文字，避免送出互相衝突的答案。
- 放大 body pain map 左右方向標示並提高字重與字距，改善定位辨識。
- 新增後端上一題狀態還原測試，以及舊版與拆分前端的選項取消／其他文字測試。

## 醫師後臺與 UCC 工作階段

- 醫師 dashboard 可在沒有 `regSno`／encounter 時啟動，保留病例查詢、醫師助手與規則
  中心；患者邀請按鈕維持可見但停用，並顯示需要先從 B.看診作業開啟就診的提示。
- 畫面新增目前就診狀態列，清楚區分一般醫師後臺與綁定 encounter 的邀請模式。
- invitation capability 同時檢查 bootstrap 能力、CSRF token 與 encounter 的 `regSno`，
  不再只依瀏覽器 token scope；送出邀請前會再次驗證目前就診一致性。
- bootstrap 將 redirect、401／403、非 JSON content type 與破損 JSON 統一辨識為 UCC
  session 失效；有效 JSON 但缺少 access token 仍保留獨立錯誤訊息。
- 新增 doctor session 回歸測試及 eHIS dashboard／invitation source contract 測試。

## 本機驗證與院所隔離

- `ALLOW_LOCAL_AUTH_BYPASS=true` 只接受 TCP peer 位址為 `127.0.0.0/8` 或 `::1` 的
  直接連線，不信任可偽造的 `Host`／forwarded header；預設與整合部署皆維持關閉。
- loopback 舊版前端可略過病患 cookie 與 UCC Bearer，並讀取尚未寫入
  `institution_id` 的歷史病例；正式 UCC principal 仍強制依院所篩選。
- 新增遠端來源拒絕、context reset、正式 principal tenant scope 與未知院所資料隔離測試。

## 結構化病歷摘要

- 醫師病歷摘要固定第一行顯示年齡、性別、主要症狀與持續時間，第二行只保留恰好兩句
  其他 EMR 病史，避免重複欄位與冗長模型輸出。
- 後端在模型摘要不安全或缺漏時，以既有過去病史、用藥與過敏資料產生 deterministic
  fallback；兩套前端也能將舊格式轉成相同顯示格式。
- 補上 prompt、rendering、舊格式相容與兩套 PatientRecordCard 測試。

## 本機 ASR 與 Avatar

- `/v1/transcribe` 預設改用延遲載入的 Breeze-ASR-26；先以 ffmpeg 解碼，再執行長度、
  RMS 靜音門檻與 MIME 對應檢查。瀏覽器只將辨識文字回填，仍由病患確認後送出。
- 新增私有 Avatar service，以 CosyVoice3 產生語音、MuseTalk 1.5 產生 MP4，支援
  content hash cache、靜態 fallback、模型下載檢查與 CUDA VRAM 釋放。
- 病患端預設使用本地 provider，也可切換鎖定版本的 `@d-id/client-sdk`；SDK 改為本地
  bundle 與延遲載入，不再從第三方 CDN 動態執行程式碼。
- Avatar status／speak 端點沿用病患 session，回傳影片時不暴露 service host；OpenAPI、
  前端型別與兩套前端實作同步更新。
