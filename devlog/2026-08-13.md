## 經審查台語問卷與問診語言鎖定

- Backend API 由 `0.4.0` 升至 `0.5.0`，development frontend 由 `0.3.0` 升至
  `0.4.0`；正式部署的 `frontend-v2` 未修改，Doctor／Patient 版號不受影響。
- 新增 Taigi-Llama-2-Translator-7B 離線轉換器，將 55 份問卷與病患流程文案輸出到
  `questionnaire_data/tai/`，保留來源／輸出 hash、固定模型 revision、HAN 目標語言、
  deterministic decoding 與 CC BY-NC-SA 4.0 授權 provenance。
- `/v1/chat` 可在 session 建立時選 `mandarin` 或 `minnan`。台語資產必須有完整 hash、
  結構 parity 及具名的 `clinically_reviewed` 簽核；缺失或未審內容以 503 fail closed，
  問診開始後若嘗試換語言則以 409 拒絕。
- 台語題目只覆蓋顯示 prompt、選項、快捷時間及單位；前端仍提交國語 canonical value，
  Backend 也只保存 canonical answer，避免條件題、FHIR 預填、semantic mapping、Gemini
  報告與既有病例因語言切換而漂移。
- 開發版 frontend 將語言選單改為問卷與醫師共用，問診開始後鎖定；結構化語音可將
  台語 label 精確映射回 canonical choice／duration value。未同步 `frontend-v2`。
