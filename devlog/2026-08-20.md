## Gemini aggregate 失敗定位與 schema 收緊

- 實際重試顯示 structured-output 後仍在最終組裝出現 `failure_stage=aggregate`；原因是
  除 must-not-miss 外的 task 原本延後到十二段全部完成後才執行本機 parser，無法指出
  哪一段違反 exact-key 契約。
- 現在每段 Gemini 回覆收到後立即驗證，且 API schema 加入
  `additionalProperties: false`；失敗會直接標示固定 task，不再只標成 aggregate。
  Backend 由 `0.11.1` 升至 `0.11.2`，33 項聚焦測試、相關 format check 與全 Backend
  Ruff check 通過；完整 suite 407 項中 405 項通過，另 2 項只因未掛載外部 eHIS C#
  原始碼而 error。
