# 2026-08-30

## Gemini transient retry 與 judge 契約修正 v0.8.1

- 唯讀稽核兩次既有 batch：共 32 筆、20 成功、12 失敗。失敗為 7 次 selector 無適用
  questionnaire、5 次 judge relation／basis contract conflict，沒有保存到 429、5xx、timeout
  或其他 `Gemini request failed`。
- Gemini provider 對 HTTP 408／429／500／502／503／504、timeout 及常見 transport
  exception 啟用有限指數退避；預設含首次請求共 3 次，並尊重上限 30 秒的數值型
  `Retry-After`。永久 client／schema／credential 錯誤仍立即失敗。
- `.env` 新增 max attempts 與 retry base seconds 研究設定，限制分別為 1–6 與 0–30 秒；
  batch manifest 記錄三個角色解析後的 retry policy，但不記 API key 或原始 provider detail。
- Retry 耗盡後的錯誤只保留 exception type、HTTP code、分類 reason、retryable 與 attempts，
  便於分辨暫時 API 故障與永久錯誤。
- Judge 的完整 relation matrix 若第一次未通過既有本機契約，會在同一 judge operation 內以
  固定 validation feedback 重試一次。這不會重跑問診、不會將 invalid relation 計分，也不會
  變更 judge 的臨床概念 matching policy。
- Selector 回傳 `questionnaire_id=null` 仍是 fail-closed abstention，不會因 batch 需要分數而
  強制重試或指派不適用問卷。這些案例需要另行決定 route catalog／一般問卷產品策略。
- Ruff lint／format、Python compileall 與 88 項 `llm_experiments` 離線測試通過；未重跑
  外部 Gemini batch，因此沒有以額外 API 成本宣稱實際錯誤率改善。

## Scenario pack 全樣本 batch runner v0.8.0

- 新增 `llm_experiments.batch_runner` CLI，依 pack JSON array 原始順序執行所有案例；
  `scenario_pack_15` 會按 Sample 1 到 Sample 16 執行，不受字串排序影響。
- Batch 在建立 Gemini provider 前一次載入並驗證整包 scenario，保留固定來源 SHA；每筆仍
  先問 CC 再選問卷，doctor、patient 與獨立 judge model 全部依 `.env` 設定。
- 每次執行建立不可覆寫的 run 目錄與開始／完成 manifest。每個案例保存完整結果 envelope，
  `scores.json` 保存逐筆 predicted／reference、分子分母、fraction 與 coverage bounds，
  `summary.json` 保存排除失敗案例的 micro／macro lower／upper aggregate。
- 單一案例的問診、provider、輸出契約或 judge 失敗會記錄精簡錯誤並繼續後續案例；完整成功、
  部分失敗與前置致命錯誤分別使用 exit code 0、1、2。API key、raw prompt 與 traceback 不寫入
  batch manifest 或錯誤結果。
- 新增離線測試涵蓋 16 筆來源順序、逐筆 artifact／score、部分失敗續跑、indeterminate
  aggregate range、run ID path traversal、不可覆寫 run 目錄，以及 env role model／secret
  隔離的 CLI 組裝。
- 這是研究執行與紀錄能力，不改變疾病 matching 臨床政策。完整 16 筆外部 Gemini batch
  涉及 API 成本，因此交付驗證只使用 fake provider，不自動送出病例。
- Ruff lint／format、Python compileall 與 82 項 `llm_experiments` 離線測試通過；環境沒有
  `backend/venv/bin/pyright`，因此未執行 Pyright。
