- 修正 FHIR 確認 dialog 使用未定義列尺寸的 CSS Grid，導致中間內容維持
  `min-height: auto` 並在小 viewport 被裁切的問題。Grid 現明確使用
  `auto minmax(0, 1fr) auto`，只有中間內容垂直捲動，header 與送出 footer 保持可見。

  優先採用 `94dvh`，並保留 `94vh` fallback。
- 新增 CSS 契約回歸測試；開發版 frontend 由 `0.13.1` 升至 `0.13.2`，Backend、
  `frontend-v2/`、FHIR API 與臨床內容均未修改。
- Node 22 的 18 個 frontend 測試檔、production build、OpenAPI type check 與 diff check
  通過。Browser plugin／Playwright 不可用，改以 headless Chrome/CDP 在 1280×900 與
  390×844 驗證：桌機內容由 0 捲至 272 px、手機由 0 捲至 630 px，兩者皆抵達底部、
  footer 保持可見且送出成功，無水平溢出、Vite overlay 或 console error。

  egress networks 均保留。
