## 開發版 QR 生日加密（frontend v0.15.0）

- 需求：患者生日為 2000 年 1 月 1 日時，以 `20000101` 解開 QR，增加一層傳遞保護。
- 決策：維持既有後端短效一次性 token／HttpOnly session 契約，在開發版 SMART launcher
  的 QR 與複製 code 外層加入生日加密。原生 Web Crypto PBKDF2-SHA256 600,000 次衍生
  AES-256-GCM key；每次隨機 salt／IV，`bqr1` 綁定格式版本並驗證完整性。未新增依賴。
- 患者掃描／貼碼後須輸入完整西元生日；錯誤生日與竄改不呼叫 exchange，生日輸入送出後
  清除，不另傳後端或寫入 storage。醫師端缺完整生日或安全加密能力時拒絕發碼。
- 修正受控 v-model 掃碼時序：等待 Vue 更新後再讀取 code，避免空值或上一筆 code 被兌換。
- 安全限制：生日低熵，可被離線猜測，仍依賴短效 token、一次性兌換與原有存取控制。
  不宣稱為強式第二因素或後端生日驗證。既有未加密碼與 UCC／重發 API 保持原行為。
- 相容性：API、資料庫不變，無遷移。正式 `frontend-v2/` 未改且不能讀取 `bqr1`，
  新格式僅用新版開發前端；正式移植需另行授權與測試。保留原有後端、README 及其他使用者修改。
